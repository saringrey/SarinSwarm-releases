Downloads for SarinSwarm test builds. SarinSwarm is a desktop app for running AI coding agents side by side on your projects.

## Download

Get the file for your computer from the [v0.1.0 release](https://github.com/saringrey/SarinSwarm-releases/releases/tag/v0.1.0):

| Your computer | File |
| --- | --- |
| Mac with Apple Silicon | `SarinSwarm-0.1.0-arm64.dmg` |
| Intel Mac | `SarinSwarm-0.1.0.dmg` |
| Windows 10 LTSC 2019 or later, or Windows 11 (x64) | `SarinsSwarm-Setup-0.1.0-x64.exe` |

## Opening it the first time

**macOS:** the app isn't notarized, so your Mac may block it. Drag it to Applications and open it once. Then go to **System Settings → Privacy & Security** and choose **Open Anyway**.

**Windows:** the installer is unsigned, so SmartScreen will warn you. Choose **More info**, then **Run anyway**.
